# DIN Voorbeelden — Referentiedocument

> Doelen-Inspanningennetwerk (DIN) — concrete voorbeelden per niveau
> Bron: Cito demo-data + "Werken aan Programma's" (Prevaas & Van Loon)

---

## De DIN-keten in een oogopslag

```
DOELEN  →  BATEN  →  VERMOGENS  →  INSPANNINGEN
(wat?)     (welk      (wat moet     (welke projecten
            effect?)   de org.       en activiteiten?)
                       kunnen?)
```

**Redeneerrichtingen:**
- **Hoe?** (links → rechts): "Hoe bereiken we dit doel?" → baten → vermogens → inspanningen
- **Waartoe?** (rechts → links): "Waartoe dient deze inspanning?" → vermogen → baat → doel

## 2. BATEN

> Gewenste effecten die bijdragen aan het nastreven van de doelen.
> Formulering: zelfstandig naamwoord + bijvoeglijk naamwoord in de **vergrotende trap** (hoger, breder, meer, korter).

### Wat is een batenprofiel?

Elke baat wordt concreet gemaakt met een **batenprofiel**:

| Veld | Betekenis |
|------|-----------|
| **Bateneigenaar** | Eindverantwoordelijk voor realisatie van de baat |
| **Indicator** | Hoe je de baat meet |
| **Indicatoreigenaar** | Verantwoordelijk voor de meting |
| **Huidige waarde** | Startwaarde (nulmeting) |
| **Doelwaarde** | Gewenste waarde |
| **Meetmoment** | Wanneer/hoe vaak wordt gemeten |

### Voorbeeld uit het programmaboek (niet-Cito)

> **Baat:** Meer gebruik hernieuwbare energie
> **Bateneigenaar:** Amber Pieterse
> **Meeteenheid:** % woningen dat grotendeels (>60%) hernieuwbare energie gebruikt
> **Startwaarde:** 10% van 47.508 woningen (2023)
> **Doelwaarde:** 75% van het aantal woningen (2040)
> **Meetwijze:** Extrapolatie o.b.v. steekproef onder 1.000 woningen
> **Meetfrequentie:** Halfjaarlijks
> **Meetverantwoordelijke:** Pieter Denekamp

### 5 validatievragen voor baten

1. Helpt de baat bij het nastreven van het achterliggende doel?
2. Heeft de baat een eigenaar die er ook verantwoordelijkheid voor neemt?
3. Is de baat helder omschreven en meetbaar gemaakt?
4. Is duidelijk wat de start- en doelwaarde zijn en hoe haalbaar die doelwaarde is?
5. Roept deze baat het gewenste gedrag op?

## 3. VERMOGENS

> Wat de organisatie moet **kunnen** om baten te realiseren.
> Een vermogen = specifieke combinatie van mensen, processen, data en systemen die in samenhang waarde toevoegen.

### Wat is een vermogensprofiel?

| Veld | Betekenis |
|------|-----------|
| **Eigenaar** | Verantwoordelijk voor ontwikkeling van het vermogen |
| **Huidige situatie (as-is)** | Hoe het er nu voorstaat |
| **Gewenste situatie (to-be)** | Hoe het eruit moet zien |
| **Huidig niveau** | Volwassenheidsscore (1-5) |
| **Doelniveau** | Gewenste volwassenheidsscore (1-5) |

### 6 aspecten van vermogens (Prevaas & Van Loon)

Bij het doorontwikkelen van een vermogen kun je naar zes aspecten kijken:

1. **Processen & prestatie-indicatoren** — Wat doet de organisatie, welke resultaten, hoe meten?
2. **Data & informatie** — Welke data wordt verzameld, verwerkt, geanalyseerd?
3. **Mensen & vaardigheden** — Harde vaardigheden (kennis) en zachte vaardigheden (empathie, communicatie)
4. **Organisatie & besturing** — Organigram, taken, bevoegdheden, verantwoordelijkheden
5. **Technologie & systemen** — IT-applicaties, hulpmiddelen, werkmethoden
6. **Cultuur & management** — Waarden, normen, leiderschapsstijl, voorbeeldgedrag

## 4. INSPANNINGEN

> Concrete projecten en activiteiten die vermogens opbouwen.
> Formulering: gebruik **werkwoorden** (inspanning = werk = werkwoord).

### De 4 inspanningsdomeinen

| Domein | Kleur | Voorbeelden |
|--------|-------|-------------|
| **Mens** | Blauw | Opleiding, training, bemensing, werving, competentieontwikkeling |
| **Processen** | Groen | Werkwijzen, procedures, governance, feedbackloops, pilots |
| **Data & Systemen** | Paars | IT-systemen, platforms, dashboards, data-infrastructuur, tooling |
| **Cultuur** | Amber | Gedrag, mindset, innovatie, partnerships, leiderschapsontwikkeling |

### Wat staat in een inspanningsdossier?

| Veld | Betekenis |
|------|-----------|
| **Eigenaar** | Opdrachtgever van de inspanning |
| **Inspanningsleider** | Projectmanager / trekker |
| **Verwacht resultaat** | Wat er concreet opgeleverd wordt |
| **Kostenraming** | Geschatte kosten met onzekerheidsmarge |
| **Randvoorwaarden** | Wat ingevuld moet zijn voor de start |
| **Kwartaal** | Geplande start |
| **Status** | Te starten / in uitvoering / in afronding |
| **Afhankelijkheden** | Inhoudelijke volgorde, gedeelde mensen |

## 6. SNELLE REFERENTIE: FORMULERINGSREGELS

| Niveau | Formulering | Voorbeeld |
|--------|-------------|-----------|
| **Doel** | Zelfstandig naamwoord + richting | "Outside-in competentie verankeren" |
| **Baat** | Zelfstandig naamwoord + **vergrotende trap** | "**Hogere** klanttevredenheid bij PO-scholen" |
| **Vermogen** | Wat de organisatie moet **kunnen** | "Klantgericht werken **is** standaard werkwijze" |
| **Inspanning** | **Werkwoord** (werk = werkwoord) | "Training outside-in werken **uitvoeren**" |

### Voorbeeld redeneerrichtingen

**Hoe-vraag** (van doel naar inspanning):
> "Hoe bereiken we *hogere klanttevredenheid*?" → Door *klantgericht werken* als standaard werkwijze te verankeren → Door een *training outside-in werken* uit te voeren

**Waartoe-vraag** (van inspanning naar doel):
> "Waartoe dient de *training outside-in werken*?" → Om het vermogen *klantgericht werken* te ontwikkelen → Om de baat *hogere klanttevredenheid* te realiseren → Om het doel *outside-in competentie verankeren* te bereiken
