**`src/lib/ooxml-tekst.ts`** (server-only, Node): 
- `export async function xlsxNaarTekst(buffer: Buffer | ArrayBuffer): Promise<string>`: open met JSZip; lees `xl/workbook.xml` (bladnamen + r:id), `xl/_rels/workbook.xml.rels` (r:id → `worksheets/sheetN.xml`), `xl/sharedStrings.xml` (`<si>`; tekst = alle `<t>` binnen een `<si>` aaneen, ook rich-text runs). Per blad in werkboekvolgorde: kop `[Tabblad: <naam>]`, dan per `<row>` de cellen (`<c r="B3" t="s|str|inlineStr|b|n">` met `<v>` of `<is><t>`): t="s" → sharedStrings[index], inlineStr → `<t>`, anders `<v>`; regel = celwaarden gescheiden door " | ", lege rijen overslaan, voorafgegaan door het rijnummer ("r3: ..."). Formules: alleen de waarde `<v>`.
- `export async function pptxNaarTekst(buffer): Promise<string>`: slides `ppt/slides/slideN.xml`, gesorteerd op N numeriek; per slide kop `[Dia N]` en per `<a:p>` de `<a:t>`-teksten aaneen (één regel per alinea). Ook sprekersnotities `ppt/notesSlides/notesSlideN.xml` als `[Notities dia N]` als ze bestaan.
- XML-parsing met reguliere expressies is acceptabel (geen nieuwe dependency); decodeer entities `&amp; &lt; &gt; &quot; &apos;` en numerieke `&#…;`. Max uitvoer BRONTEKST_MAX (uit bronnenanalyse-service).

1. multipart `file` (FormData);

3. JSON `{ url: string, bestandsnaam?: string }` → server-side fetch, ALLEEN als de url begint met `${process.env.NEXT_PUBLIC_SUPABASE_URL}/storage/v1/object/public/sessie-documenten/` of `.../public/3sides-documenten/` (SSRF-guard: parse met `new URL`, vergelijk origin + pathname-prefix, geen redirects volgen: `redirect: "error"`); anders `code: "url_niet_toegestaan"`. Dit omzeilt de 4,5 MB request-limiet voor grote bestanden.
Type bepalen met `bronTypeUitBestandsnaam` (bestandsnaam uit file.name, body of laatste url-segment, decodeURIComponent). Parsing: pdf → pdf-parse (exact het dynamische-importpatroon uit parse-projects r.24-28); docx/doc → `mammoth.extractRawText`; txt/md/eml/html → utf-8 tekst (html: tags strippen); xlsx → `xlsxNaarTekst`; pptx → `pptxNaarTekst`; msg en overige → `code: "onbekend_type"` met melding "Dit bestandstype kan niet gelezen worden.
