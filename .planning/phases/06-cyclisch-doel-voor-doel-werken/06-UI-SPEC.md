## Component Inventory (Phase 6 Changes)

### 1. GoalStatusBadge (new, inline in DINMappingStep)

Replaces the existing green dot (`text-green-400 \u25CF`) per D-12.

**States:**

| State | Visual | Implementation |
|-------|--------|----------------|
| `afgerond` | Green checkmark | `<span className="ml-1 text-green-500 text-xs">&#10003;</span>` |
| `bezig` | Per-sector mini indicators | See "Per-Sector Mini Status" below |
| `niet-begonnen` | Gray open circle | `<span className="ml-1 text-gray-300 text-xs">&#9675;</span>` |

**Per-Sector Mini Status (for `bezig` state, per D-11):**

```
PO+ VO- Za-
```

Format: 2-letter sector abbreviation followed by `+` (green-600, chain complete) or `-` (gray-300, chain incomplete). Rendered inline after goal name, `text-[10px]` size, `gap-0.5` between items.

Sector abbreviations: `PO`, `VO`, `Za` (short for Zakelijk).

### 2. DoelAfrondenButton (new, inline in DINMappingStep sidebar)

Positioned directly below the goals list within the sidebar (`w-56`), per D-02.

**Enabled state (all sectors have complete chains):**
- Classes: `w-full px-3 py-2 bg-emerald-600 text-white text-sm font-medium rounded-lg hover:bg-emerald-700 transition-colors`
- Label: "Doel afronden"
- Icon: Inline SVG checkmark (16x16) before label
- Behavior: On click, adds goal ID to `completedGoals[]`, shows success toast "Doel afgerond!", auto-advances to next incomplete goal

**Disabled state (chain incomplete in one or more sectors):**
- Classes: `w-full px-3 py-2 bg-gray-100 text-gray-400 text-sm rounded-lg cursor-not-allowed`
- Label: "Doel afronden"
- Below the button: missing chain summary in `text-xs text-gray-500`, e.g.:
  - "VO: mist vermogens, inspanningen"
  - "Zakelijk: mist baten, vermogens, inspanningen"

**Disabled during AI generation:**
- Same disabled styling as above
- Label: "Bezig met genereren..."

**Confirmation approach:** No confirmation dialog. Direct action per D-02 (user is free to navigate, un-completing is possible).

### 3. Sidebar Auto-Advance Behavior (modification to DINMappingStep)

Per D-01: After clicking "Doel afronden":
1. Goal is marked as completed (session update)
2. Toast appears: "Doel afgerond!" (success, 3 seconds)
3. After 300ms delay, sidebar advances to the next incomplete goal (sorted by `goal.rank`)
4. If all goals are complete, sidebar stays on current goal, toast reads: "Alle doelen afgerond!"

Transition: No animation on the sidebar jump. The active goal highlight (`bg-cito-blue text-white`) simply moves to the next goal. The `slide-in-right` animation from globals.css is NOT used here -- it is reserved for panels.

### 4. Un-Complete Toggle (for completed goals)

When a completed goal is selected in the sidebar, the "Doel afronden" button area shows:
- Text: "Dit doel is afgerond" in `text-xs text-green-600`
- Link: "Markering opheffen" in `text-xs text-cito-blue hover:underline cursor-pointer`
- Behavior: Removes goal ID from `completedGoals[]`, reverts badge to `bezig` state

## Interaction Contract

### Goal Selection (existing, unchanged per D-01)

| Action | Result |
|--------|--------|
| Click any goal in sidebar | Goal becomes active. No warning dialog. DIN editor shows that goal's items. |
| Click completed goal | Goal becomes active. Shows "Dit doel is afgerond" with un-complete option. |
| Click unstarted goal | Goal becomes active. DIN editor shows empty state for that goal. |

### Doel Afronden Flow

| Step | Actor | Result |
|------|-------|--------|
| 1. User works on a goal across all sectors | User | Status badge changes from `niet-begonnen` to `bezig` as items are added |
| 2. All three sectors have complete chains | System | "Doel afronden" button becomes enabled (green) |
| 3. User clicks "Doel afronden" | User | Goal added to `completedGoals[]` |
| 4. System feedback | System | Toast: "Doel afgerond!" (success), badge becomes green checkmark |
| 5. Auto-advance (300ms delay) | System | Active goal switches to next incomplete goal by rank |
| 6. AI context updated | System | Next AI generation includes completed goal items in prompt |

### Disabled Button Feedback

When user hovers over disabled "Doel afronden" button, no tooltip. The missing items are always visible below the button as static text (not on hover). This ensures the user always sees what is needed.

## State-to-Visual Mapping

| Session State | Visual Indicator |
|---------------|-----------------|
| `completedGoals.includes(goalId)` | Green checkmark badge, "Dit doel is afgerond" text |
| Goal has items in ANY sector but NOT in `completedGoals` | `bezig` badge with per-sector mini status |
| Goal has NO items in ANY sector | Gray open circle badge |
| All sectors have complete chain AND NOT in `completedGoals` | "Doel afronden" button enabled (green) |
| Any sector missing chain items | "Doel afronden" button disabled with missing items listed |
| `isGenerating === true` | "Doel afronden" button disabled with "Bezig met genereren..." |
| All goals in `completedGoals` | Toast: "Alle doelen afgerond!" on last completion |

**"bezig" detection logic:** A goal is `bezig` (in progress) when it has at least one DIN item (benefit, capability, or effort) linked to it in any sector, but is not in the `completedGoals` array. This is determined by checking if any `goalBenefitMap` entries exist for this goal across all sectors.

## Accessibility Notes

- Status badges use Unicode characters (checkmark U+2713, circle U+25CB) that are screen-reader accessible
- All interactive elements (goal buttons, afrond-knop) use native `<button>` elements
- Disabled "Doel afronden" button uses `disabled` attribute (not just visual styling) for keyboard accessibility
- Missing chain text is always visible (not hidden behind hover/tooltip) for cognitive accessibility
- Color is not the sole differentiator: checkmark vs circle vs sector abbreviations provide shape/text differentiation alongside color
