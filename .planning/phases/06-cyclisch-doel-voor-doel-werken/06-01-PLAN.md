Add these exported types and functions AFTER the existing `getStepCompletions` function (around line 641):

```typescript
// --- Doel-voor-Doel Voortgang (Phase 6) ---

export interface SectorChainStatus {
  hasBenefits: boolean;
  hasCapabilities: boolean;
  hasEfforts: boolean;
  isComplete: boolean;
  missing: string[]; // e.g., ["mist baten", "mist vermogens"]
}

export type GoalStatus = "afgerond" | "bezig" | "niet-begonnen";

export interface GoalCompletionStatus {
  goalId: string;
  status: GoalStatus;
  sectorStatuses: Record<string, SectorChainStatus>;
  isComplete: boolean;
  isManuallyCompleted: boolean;
}
```

Implement `checkSectorChain(session: DINSession, goalId: string, sectorId: string): SectorChainStatus`:
1. Find benefits for this goal+sector: filter `session.goalBenefitMaps` by goalId, get benefitIds, then filter `session.benefits` by those IDs AND sectorId
2. Find capabilities linked to those benefits: filter `session.benefitCapabilityMaps` by the found benefitIds, get capabilityIds, then filter `session.capabilities` by those IDs AND sectorId
3. Find efforts linked to those capabilities: filter `session.capabilityEffortMaps` by the found capabilityIds, get effortIds, then filter `session.efforts` by those IDs AND sectorId
4. Build missing array: if no benefits -> "mist baten", if no capabilities -> "mist vermogens", if no efforts -> "mist inspanningen"
5. isComplete = hasBenefits AND hasCapabilities AND hasEfforts

Implement `getGoalCompletionStatus(session: DINSession, goalId: string): GoalCompletionStatus`:
1. Check if goalId is in `(session.completedGoals ?? [])` -> if yes, status = "afgerond", isManuallyCompleted = true
2. For each sector in SECTORS ("PO", "VO", "Zakelijk"), call checkSectorChain
3. isComplete = all three sectorStatuses are isComplete
4. Determine status: if isManuallyCompleted -> "afgerond"; else if any sector has any items (hasBenefits || hasCapabilities || hasEfforts) -> "bezig"; else -> "niet-begonnen"
5. Return { goalId, status, sectorStatuses, isComplete, isManuallyCompleted }
