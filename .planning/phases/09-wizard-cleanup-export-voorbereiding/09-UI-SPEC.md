The AI button bar simplifies from 3 buttons to 1 button:

**Before (current):**
```
[AI: Genereer DIN-netwerk] [Integratie-advies] [clipboard icon]
```

**After (target):**
```
[AI: Genereer DIN-netwerk]
```

Button style remains unchanged:
- `px-4 py-2 bg-cito-accent text-white rounded-lg text-sm font-medium hover:bg-cito-blue disabled:opacity-50`
- Positioned: `flex justify-end gap-2` (gap-2 still valid for future button additions, no layout change needed)

### ExportStep Sectorale Uitwerking (AFTER cleanup)

Each sector section renders:
1. Sector heading: `text-sm font-bold text-cito-blue`
2. Baten table (unchanged)
3. Vermogens table (unchanged)
4. Inspanningen per domein table (unchanged)
5. ~~Integratie-advies~~ (REMOVED -- no replacement per D-09)

The `border-l-4` sector accent and `pl-5` padding remain unchanged.

### Wizard Flow (unchanged per 09-CONTEXT.md code_context)

The 6-step wizard flow is NOT modified:
1. Import & Opzet
2. Sectorwerk
3. DIN-Mapping (cleaned up internally, step intact)
4. Prioritering
5. Cross-Analyse
6. Export (cleaned up internally, step intact)

`APP_STEPS` in types.ts and `AppStepSchema` in schemas.ts are NOT modified.
