## Interaction States

### SyncStatusFooter State Machine

```
[app start]
  |
  v
isSupabaseConfigured? --NO--> OFFLINE (gray, permanent)
  |
  YES
  |
  v
SYNCED (green)
  |
  [updateSession called]
  v
SYNCING (orange, animate-pulse)
  |
  [Supabase save succeeds] --> SYNCED (green, update lastSyncTime)
  |
  [Supabase save fails, retry 1-3]
  |
  [All retries exhausted] --> ERROR (red)
  |
  [Next successful save] --> SYNCED (green)
```

### Transitions

| From | To | Trigger | Animation |
|------|-----|---------|-----------|
| synced | syncing | Supabase save starts | Dot transitions to orange with `animate-pulse` |
| syncing | synced | Save succeeds | Dot transitions to green, pulse stops, timestamp updates |
| syncing | error | All 3 retries fail | Dot transitions to red, pulse stops |
| error | syncing | Next save attempt | Dot transitions to orange with pulse |
| offline | (none) | Permanent state | No transitions possible |

Note: No CSS transition on the dot color change. The color swap is instantaneous via class toggle. Only the `animate-pulse` provides motion during syncing.

## Layout Impact

### Fixed Footer Clearance

All pages that show `SyncStatusFooter` need bottom padding to prevent content from being hidden behind the fixed footer.

| Page | Current bottom padding | Required change |
|------|----------------------|-----------------|
| `src/app/page.tsx` | None | Add `pb-12` to main content container |
| `src/app/sessies/[id]/page.tsx` | None | Add `pb-12` to main content container |

### Toast Position Conflict

Existing Toast component renders at `fixed bottom-4 right-4 z-50`. With the new footer at `fixed bottom-0`, toasts must render ABOVE the footer.

| Element | Current position | New position |
|---------|-----------------|--------------|
| Toast container | `bottom-4 right-4` | `bottom-12 right-4` (48px from bottom, clears footer) |
| SyncStatusFooter | N/A (new) | `bottom-0 inset-x-0` |

### Provider Nesting Order

```
<ClientProviders>        <!-- layout.tsx -->
  <ToastProvider>        <!-- existing -->
    <SyncStatusProvider> <!-- NEW: add here -->
      {children}
      <SyncStatusFooter />  <!-- renders inside SyncStatusProvider -->
    </SyncStatusProvider>
  </ToastProvider>
</ClientProviders>
```
