<objective>
Replace the broken Dutch tokenizer with a Snowball stemmer-based implementation that produces meaningful tokens for cross-analyse similarity matching.

Purpose: The current tokenize() function in din-service.ts generates garbage tokens by splitting every word >= 8 chars at every position (e.g., "onderwijskwaliteit" produces "onde", "rwij", "ijskw"). Combined with a 0.20 Jaccard threshold, unrelated benefits and efforts are falsely clustered. This plan fixes the tokenizer and raises the threshold to produce meaningful cross-sector clusters.

Output: A new `nl-tokenizer.ts` module with Snowball stemmer, expanded stopwords, conservative compound splitting, and raised threshold (0.35). The existing din-service.ts cluster functions are rewired to use the new module. All behavior verified by unit tests.
</objective>
