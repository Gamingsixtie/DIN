    a) `extractJSON(raw: string): string | null` — export functie:
    ```typescript
    export function extractJSON(raw: string): string | null {
      const cleaned = raw
        .replace(/^```(?:json)?\s*/i, "")
        .replace(/\s*```\s*$/i, "")
        .trim();
      try { JSON.parse(cleaned); return cleaned; } catch {}
      const match = cleaned.match(/\{[\s\S]*\}/);
      if (match) {
        try { JSON.parse(match[0]); return match[0]; } catch {}
      }
      return null;
    }
    ```

    b) `ParseResult<T>` type:
    ```typescript
    type ParseResult<T> =
      | { success: true; data: T }
      | { success: false; error: string; retryable: boolean };
    ```

    c) `parseAIResponse<T>(raw: string, schema: z.ZodType<T>): ParseResult<T>` — export functie:
    - Roep `extractJSON(raw)` aan
    - Als null: return `{ success: false, error: "Geen geldig JSON in AI-antwoord", retryable: true }`
    - `JSON.parse()` het resultaat. Als dat faalt: return `{ success: false, error: "Ongeldig JSON formaat", retryable: true }`
    - `schema.safeParse(parsed)`. Als dat faalt: return `{ success: false, error: "Onverwachte AI-structuur: " + issues map to messages, retryable: true }`
    - Bij succes: return `{ success: true, data: result.data }`

    d) `callClaudeWithValidation<T>(schema: z.ZodType<T>, systemPrompt: string, userMessage: string, options?: { maxTokens?: number; model?: string }): Promise<{ success: true; data: T } | { success: false; error: string }>` — export functie:
    - `const MAX_RETRIES = 2;`
    - Loop: `for (let attempt = 0; attempt <= MAX_RETRIES; attempt++)`
    - Roep `callClaude(systemPrompt, userMessage, options?.maxTokens, options?.model)` aan
    - Roep `parseAIResponse(raw, schema)` aan
    - Bij success: return direct
    - Bij failure: sla `lastError` op, ga door met volgende poging
    - Na alle pogingen: return `{ success: false, error: lastError }`
