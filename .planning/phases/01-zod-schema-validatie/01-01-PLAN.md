    **Stap 2: Maak `src/lib/schemas.ts`** (per D-10 — een centraal bestand) met de volgende structuur:

    ```typescript
    import { z } from "zod";
    ```

    **Enums & Literals:**
    - `EffortDomainSchema = z.enum(["mens", "processen", "data_systemen", "cultuur"])`
    - `EffortStatusSchema = z.enum(["gepland", "in_uitvoering", "afgerond", "on_hold"])`
    - `ApprovalStatusSchema = z.enum(["voorstel", "goedgekeurd", "afgewezen", "aangepast"])`
    - `PrioritySchema = z.enum(["hoog", "midden", "laag"])`
    - `SectorNameSchema = z.enum(["PO", "VO", "Zakelijk"])`
    - `AppStepSchema = z.enum(["import", "sectorwerk", "din-mapping", "cross-analyse", "prioritering", "export"])`

    **Sub-schemas (profielen):**
    - `BatenProfielSchema` — alle velden uit huidige `BatenProfiel` interface. `bateneigenaar`, `meetmethode`, `measurementMoment` zijn `.optional().default("")`. `indicator`, `indicatorOwner`, `currentValue`, `targetValue` zijn `z.string()`.
    - `VermogensProfielSchema` — `eigenaar`, `huidieSituatie`, `gewensteSituatie` als `z.string()`.
    - `InspanningsDossierSchema` — `eigenaar`, `inspanningsleider`, `verwachtResultaat`, `kostenraming`, `randvoorwaarden` als `z.string()`.

    **Entity schemas (storage — met id velden):**
    - `ProgrammeGoalSchema` — id, name, description, rank: z.number(), sourceSessionId optional
    - `ProgrammeVisionSchema` — id, uitgebreid, beknopt, sourceSessionId optional
    - `ProgrammeScopeSchema` — id, inScope: z.array(z.string()), outScope: z.array(z.string())
    - `SectorPlanSchema` — id, sectorName, rawText, parsedContent: z.record(z.string(), z.unknown()).optional(), uploadedAt
    - `PMCEntrySchema` — id, product, marketSegment, priority: PrioritySchema, currentPerformance optional
    - `DINBenefitSchema` — id, goalId, sectorId, title: z.string().optional().default(""), description, profiel: BatenProfielSchema
    - `DINCapabilitySchema` — id, sectorId, title optional default "", description, relatedSectors: z.array(z.string()), currentLevel: z.number().optional(), targetLevel: z.number().optional(), profiel: VermogensProfielSchema.optional()
    - `DINEffortSchema` — id, sectorId, title optional default "", description, domain: EffortDomainSchema, quarter optional, responsibleSector optional, status: EffortStatusSchema, dependencies: z.array(z.string()), votes: z.number().optional(), opmerking optional, approvalStatus: ApprovalStatusSchema.optional(), approvalDate optional, dossier: InspanningsDossierSchema.optional()
    - `ExternalProjectSchema` — id, sectorId, name, description, status: EffortStatusSchema, relevance optional
    - Mapping schemas: `GoalBenefitMapSchema`, `BenefitCapabilityMapSchema`, `CapabilityEffortMapSchema`, `EffortPMCMapSchema`, `EffortSectorMapSchema`

    **Analyse result schemas:**
    - `SectorplanAnalyseResultSchema` — exact de structuur van `SectorplanAnalyseResult` in types.ts, met inspanningen-sub-object (mens, processen, data_systemen, cultuur als string arrays)
    - `CrossAnalyseResultSchema` — exact de structuur van `CrossAnalyseResult` met sub-schemas voor synergie, gaps, hefboomwerking, domeinBalans, sectorOverlap, externeProjecten
    - `IntegratieAdviesResultSchema` — sectorName + 5 sub-items (aansluiting, verrijking, aanvullingen, quickWins, aandachtspunten)

    **DINSession schema:**
    - `DINSessionSchema` — alle velden van DINSession. Arrays krijgen `.default([])`. Optional velden blijven optional. `sectorAnalyses`, `verrijkteSectorplannen` zijn `z.record(z.string(), z.string()).optional()`. `crossAnalyse` is `z.string().optional()`. `integratieAdvies` is `z.record(z.string(), z.union([IntegratieAdviesResultSchema, z.string()])).optional()`.

    **AI Response schemas (ZONDER id/goalId/sectorId — per Pitfall 6 uit RESEARCH.md):**
    - `AIBenefitSchema` — title, description, profiel (met alle velden optional met defaults behalve title en description)
    - `AICapabilitySchema` — title, description, currentLevel optional, targetLevel optional, profiel optional
    - `AIEffortSchema` — title, description, domain: EffortDomainSchema, quarter optional, dossier optional
    - `AIDINMappingResponseSchema = z.object({ benefits: z.array(AIBenefitSchema), capabilities: z.array(AICapabilitySchema), efforts: z.array(AIEffortSchema) })`
    - `AISuggestBaatSchema` — title optional, description, profiel object met alle velden optional
    - `AISuggestVermogenSchema` — title optional, description, currentLevel optional, targetLevel optional, profiel optional
    - `AISuggestInspanningSchema` — title optional, description, domain: EffortDomainSchema.optional(), quarter optional, dossier optional
    - `AISectorplanAnalyseSchema` — zelfde structuur als `SectorplanAnalyseResultSchema` maar met `.optional().default()` op alle geneste velden voor robuustheid bij AI output
    - `AICrossAnalyseSchema` — zelfde structuur als `CrossAnalyseResultSchema` met soepelere defaults
    - `AIIntegratieAdviesSchema` — zelfde structuur als `IntegratieAdviesResultSchema` met defaults
    - `AIDomainRecommendSchema = z.object({ domain: EffortDomainSchema, reasoning: z.string() })`

    **KiB Import schema (per D-06):**
    - `KiBExportSchema` — visie optional, doelen array optional default [], scope optional, sessionId optional

    **Type exports (onderaan schemas.ts):**
    - Export alle types via `export type X = z.infer<typeof XSchema>` voor elk schema
