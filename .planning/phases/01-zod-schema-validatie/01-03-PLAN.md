<objective>
Valideer externe input (KiB import) met Zod, verwijder client-side JSON parsing uit componenten die nu gevalideerde data van de API ontvangen, en implementeer het retryable feedback tekstveld in alle AI-aanroepende componenten (per D-03).

Purpose: Per D-06 moet alle externe input consistent gevalideerd worden. De client-side `match(/\{[\s\S]*\}/)` + `JSON.parse` patronen in 3 componenten zijn niet meer nodig omdat Plan 02 de API routes al gestructureerde (Zod-gevalideerde) objecten laat retourneren. Daarnaast implementeert dit plan het D-03 UI-patroon: wanneer een API response `retryable: true` bevat, toont de component een tekstveld waarmee de gebruiker extra instructies kan meegeven voor een nieuwe AI-poging.

Output: Gevalideerde KiB import, opgeschoonde client componenten zonder handmatige JSON parsing, retryable feedback UI in alle AI-aanroepende componenten, tests voor KiB validatie.
</objective>

export const KiBExportSchema = z.object({
  visie: z.object({

    **DEEL B: Retryable feedback tekstveld (per D-03)**

    Implementeer in ALLE componenten die AI endpoints aanroepen een patroon dat het volgende doet:
    1. Na een `fetch()` naar een AI endpoint, check `json.retryable === true` in de error response
    2. Als `retryable` is `true`, toon naast de foutmelding een tekstveld (`<textarea>`) met een label als "Geef extra instructies mee voor een nieuwe poging"
    3. De gebruiker kan tekst typen en op "Opnieuw proberen" klikken
    4. Bij de retry wordt de extra instructie meegegeven in de request body als `userFeedback: string`
    5. Als de retry slaagt, verdwijnt het tekstveld en wordt de data normaal verwerkt

    **Implementatie-patroon per component:**

    Voeg twee state variabelen toe:
    ```typescript
    const [aiRetryable, setAiRetryable] = useState(false);
    const [userFeedback, setUserFeedback] = useState("");
    ```

    In de fetch error handler:
    ```typescript
    if (json.retryable) {
      setAiRetryable(true);
      setAiError(json.error); // bestaande error state
    }
    ```

    In de JSX, onder de bestaande foutmelding:
    ```tsx
    {aiRetryable && (
      <div className="mt-3 space-y-2">
        <label className="block text-sm font-medium text-gray-700">
          Geef extra instructies mee voor een nieuwe poging
        </label>
        <textarea
          value={userFeedback}
          onChange={(e) => setUserFeedback(e.target.value)}
          className="w-full rounded-md border border-gray-300 p-2 text-sm"
          rows={3}
          placeholder="Bijv. 'Focus op meetbare indicatoren' of 'Houd het korter'"
        />
        <button
          onClick={() => handleRetryWithFeedback()}
          className="rounded-md bg-[#003366] px-4 py-2 text-sm text-white hover:bg-[#002244]"
        >
          Opnieuw proberen
        </button>
      </div>
    )}
    ```

    De `handleRetryWithFeedback` functie roept dezelfde fetch aan maar voegt `userFeedback` toe aan de request body. Na een succesvolle retry: `setAiRetryable(false); setUserFeedback("");`
