    ```
    /\b(hogere?|lagere?|snellere?|betere?|grotere?|bredere?|sterkere?|diepere?|rijkere?|kortere?|langere?)\b/i
    /\b(meer|minder)\b/i
    ```

       - Rule 1 (vergrotende trap): Check title against VERGROTENDE_TRAP_PATTERNS. If missing, auto-correct by prepending "Betere " + lowercase first char. Push to corrections with rule="vergrotende-trap", message="Titel aangepast naar vergrotende trap".

       - Rule 1 (geen actie-werkwoorden): Check title against ACTION_VERBS_BLACKLIST. If found, push warning. Message: `Titel bevat actie-werkwoord "${verb}" -- vermogens beschrijven wat de organisatie moet KUNNEN, niet DOEN`.

    3. `validateInspanning(inspanning: { title: string; domain?: string; [key: string]: unknown }): ValidationResult<typeof inspanning>`

       - Rule 2 (kort): If title >8 words, push warning.

    All three functions return `{ item: correctedItem, passed: corrections.length === 0 && warnings.length === 0, corrections, warnings }`.
