    **Types:**

    export interface ValidationCorrection {
      field: string;

    **Dutch word lists (domain-specific, NOT full NLP):**

    ACTION_VERBS_BLACKLIST (for baat + vermogen titles -- these are inspanning-words):
    ```
    "implementeren", "uitvoeren", "opzetten", "inrichten", "trainen",
    "bouwen", "ontwikkelen", "realiseren", "verbeteren", "optimaliseren",
    "lanceren", "deployen", "migreren", "invoeren", "organiseren",
    "aanschaffen", "installeren", "configureren", "integreren", "automatiseren"
    ```

    VERGROTENDE_TRAP_PATTERNS (regex array for baat titles):
    ```
    /\b(hogere?|lagere?|snellere?|betere?|grotere?|bredere?|sterkere?|diepere?|rijkere?|kortere?|langere?)\b/i
    /\b(meer|minder)\b/i
    ```
    Note: Do NOT use generic -er/-ere suffix matching (Pitfall 4 -- too many false positives). Stick to the curated list.

    VERGROTENDE_PREFIXES for auto-correction: `["Betere"]` as safe default.

    **Validator functions:**

    1. `validateBaat(baat: { title: string; [key: string]: unknown }): ValidationResult<typeof baat>`
       - Rule 1 (vergrotende trap): Check title against VERGROTENDE_TRAP_PATTERNS. If missing, auto-correct by prepending "Betere " + lowercase first char. Push to corrections with rule="vergrotende-trap", message="Titel aangepast naar vergrotende trap".
       - Rule 2 (geen werkwoorden): Check title words against ACTION_VERBS_BLACKLIST. If found, push warning with the verb name. Message: `Titel bevat werkwoord "${verb}" -- baten beschrijven effecten, geen activiteiten`.
       - Rule 3 (kort): If title >5 words, push warning. Message: `Titel heeft ${n} woorden (max 5 aanbevolen)`.

    2. `validateVermogen(vermogen: { title: string; [key: string]: unknown }): ValidationResult<typeof vermogen>`
       - Rule 1 (geen actie-werkwoorden): Check title against ACTION_VERBS_BLACKLIST. If found, push warning. Message: `Titel bevat actie-werkwoord "${verb}" -- vermogens beschrijven wat de organisatie moet KUNNEN, niet DOEN`.
       - Rule 2 (kort): If title >5 words, push warning.

    3. `validateInspanning(inspanning: { title: string; domain?: string; [key: string]: unknown }): ValidationResult<typeof inspanning>`
       - Rule 1 (werkwoorden verplicht): Check if ANY word in title matches ACTION_VERBS_BLACKLIST or common verbs list (uitvoeren, trainen, etc.). If NO verb found, push warning. Message: `Titel mist een werkwoord -- inspanningen beschrijven concrete acties`.
       - Rule 2 (kort): If title >8 words, push warning.

    All three functions return `{ item: correctedItem, passed: corrections.length === 0 && warnings.length === 0, corrections, warnings }`.

    Use vitest (describe/it/expect). Create test cases per the behavior list above. Group by DIN type.
