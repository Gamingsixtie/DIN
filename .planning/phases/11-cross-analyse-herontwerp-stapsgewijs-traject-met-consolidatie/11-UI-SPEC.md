## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding (`gap-1`, `px-1.5`) |
| sm | 8px | Compact element spacing, button gaps (`gap-2`) |
| md | 16px | Default element spacing, card padding (`p-4`) |
| lg | 20px | Section padding within cards (`p-5`, existing pattern) |
| xl | 24px | Layout gaps between sections (`space-y-6`) |
| 2xl | 32px | Major section breaks, wizard step content padding (`space-y-8`) |
| 3xl | 64px | Empty state vertical padding (`py-16`) |

Exceptions:
- Touch targets use `min-h-[44px]` on all interactive buttons (existing pattern from ConsolidationActionBar)
- Wizard progress indicator circles use `w-10 h-10` (40px, established in LoadingOverlay DIN chain animation)
- Wizard step content area uses `p-6` (24px) for comfortable reading in the active step panel

Source: existing CrossAnalyseStep.tsx patterns (SectorBadge `px-1.5 py-0.5`, cards `p-4`/`p-5`, section spacing `space-y-4`/`space-y-8`).

## Interaction States

### Step Completion Logic (D-01)

| Step | Completed when |
|------|---------------|
| 1 | User has reviewed baten data (viewed step) OR ran AI analysis |
| 2 | User has reviewed vermogen clusters OR ran AI analysis |
| 3 | User has reviewed inspanning clusters OR ran AI analysis |
| 4 | At least one consolidation decision made (merge, review, or apart houden) per cluster, OR step viewed |
| 5 | Always accessible once step 4 is complete (read-only summary) |

Navigation rules:
- BACK navigation: always allowed to any previously visited step
- FORWARD navigation: only to next step when current step is completed
- Clicking a completed step in the progress bar navigates directly to that step
- Clicking a locked step shows a tooltip: "Rond eerst de vorige stap af"

### Wizard State Persistence

Wizard state is persisted to session on every step completion and consolidation action. On mount:
1. If `crossAnalyseWizard` exists in session: restore wizard state (current step, completed steps, step results)
2. If only `crossAnalyse` (old format) exists: show "Eerdere analyse gevonden" notice with options to view or start fresh
3. If neither exists: start wizard at step 1
