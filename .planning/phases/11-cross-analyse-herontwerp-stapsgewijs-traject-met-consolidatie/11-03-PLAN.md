interface WizardState {
  currentStep: number;
  completedSteps: Set<number>;
  stepResults: {
    stap1?: Stap1Result;
    stap2?: Stap2Result;

    stap4?: Stap4Result;

  };

**State management:**
- `wizardState: WizardState` with `useState`
- `isLoading: boolean` for current AI call
- `error: string | null` for current step error
- `userFeedback: string` for optional context textarea
- Toast messages via existing session toast pattern

**Initialization (useEffect on mount):**
1. If `session.crossAnalyseWizard` exists: restore wizard state from session (currentStep, completedSteps as Set from array, stepResults)
2. If only `session.crossAnalyse` (old format) exists and no `crossAnalyseWizard`: show "Eerdere analyse gevonden" banner with two buttons: "Bekijk eerdere analyse" (sets a showLegacy flag) and "Nieuwe analyse starten" (starts wizard at step 1). This is the `legacyMode` state.
3. If neither exists: start at step 1

**Step completion handler:**
```typescript
const handleStepComplete = useCallback((stepNum: number, result: unknown) => {
  setWizardState(prev => {
    const newCompleted = new Set(prev.completedSteps);
    newCompleted.add(stepNum);
    const newStepResults = { ...prev.stepResults, [`stap${stepNum}`]: result };
    // Persist to session
    updateSession(s => ({
      ...s,
      crossAnalyseWizard: {
        currentStep: prev.currentStep,
        completedSteps: Array.from(newCompleted),
        stepResults: newStepResults,
      },
    }));
    return {
      ...prev,
      completedSteps: newCompleted,
      stepResults: newStepResults,
    };
  });
}, [updateSession]);
```

**AI call handler:**
Generic per-step AI call that:
1. Sets isLoading=true
2. Constructs request body with session DIN data (goals, benefits, capabilities, efforts, externalProjects, maps) + stap number + prior step results + optional userFeedback
3. POSTs to `/api/cross-analyse` with `stap: currentStep`
4. On success: calls `handleStepComplete(currentStep, result.data.analysis)`
5. On error: sets error with retry option
6. Sets isLoading=false

Request body structure:
```typescript
const requestBody = {
  stap: wizardState.currentStep,
  goals: session.goals,
  benefits: session.benefits,
  capabilities: session.capabilities.filter(c => !c.consolidated),
  efforts: session.efforts.filter(e => !e.consolidated),
  externalProjects: session.externalProjects || [],
  goalBenefitMaps: session.goalBenefitMaps,
  benefitCapabilityMaps: session.benefitCapabilityMaps,
  capabilityEffortMaps: session.capabilityEffortMaps,
  stap1Result: wizardState.stepResults.stap1,
  stap2Result: wizardState.stepResults.stap2,
  stap3Result: wizardState.stepResults.stap3,
  stap4Result: wizardState.stepResults.stap4,
  userFeedback: userFeedback || undefined,
};
```
